# Examples

Paste these into the inspector to compare their structure:

- Precomposed: `Café`
- Combining mark: `Café`
- Emoji joined into one grapheme: `👨‍👩‍👧‍👦`
- Multilingual text: `Hello, 世界 مرحبا`
- Look-alike letters: `paypaI` (the last character is uppercase `I`)

The **Hidden space** sample button in the app includes a zero-width space between `alpha` and `beta`.
